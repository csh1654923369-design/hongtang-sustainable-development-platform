# 地图服务素材

本目录保存从三农数据GeoServer下载的红塘村地图图层。下载日期为2026年7月29日，坐标系为EPSG:4326。

## 已下载文件

- `红塘村建筑图层_WMS_2048x3200.png`：第一条WMS地址生成的透明PNG。
- `红塘村建筑图层_WFS_原始.geojson`：第一条图层对应的WFS原始数据，共1490个建筑面。
- `红塘村手绘图层_WMS_2048x2870.png`：第二条“Shouhuitu”图层生成的透明PNG。
- `图层信息.json`：记录网站叠加图片时需要的坐标范围和文件关系。
- `来源地址.txt`：保存用户提供的两条原始WMS预览地址。

## 使用说明

两张PNG都可以按照`图层信息.json`中的`bounds`覆盖到二维地图上。建筑图层还可使用GeoJSON做可点击建筑；手绘图层只提供WMS栅格服务，WFS请求会返回“Feature type unknown”，因此应使用PNG或在线WMS方式加载。

GeoJSON原始属性中包含户主姓名、联系电话、家庭住址等调查字段的字段名。即使当前不少值为空，也不要把原始文件上传到公开GitHub仓库或直接发送给浏览器。平台如需使用，应先生成只保留建筑编号、类型、高度和轮廓的安全版本。
