# 红塘村可持续发展平台

当前线上版本为 **V1.2**。

公开访问地址：<https://csh1654923369-design.github.io/hongtang-sustainable-development-platform/>

V1.2以一张地图作为统一入口，通过“小花园、茶产业、村里用水、塌方与安全、历史与文化”五个专题，帮助使用者沿着“问题—关系—尺度—证据—行动”理解红塘村。2D地图、3D实景和轻量地图编辑器共用同一套专题与空间资料。

仓库只发布最新版本的`平台源码`及公开运行所需素材；V1.0、V1.1等历史快照只保存在本地，不上传GitHub。

详细说明见[平台源码/README.md](平台源码/README.md)。
