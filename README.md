# 红塘村可持续发展平台 Demo

平台当前采用单一首页结构，不再设置固定顶栏、TAB、搜索、地图或记录入口。页面左上角使用悬浮框显示平台Logo和“红塘村可持续发展平台”名称，右侧等高排列“2D地图 / 3D实景”切换按钮。首页默认显示2D地图；2D以高德在线地图为云端底层，可叠加红塘无人机影像或手绘图，3D以Cesium地形和高斯模型为底层。两种模式读取同一套地点、分类、图标、详情和点线面专题数据，只改变呈现维度。地图左上角的“专题”是位于两种地图之上的同一个持久组件，切换视图时不会卸载，已勾选图层会继续生效；“村里用水专题”也从该组件进入，不再单独占用左下角。

> 当前首页使用“平台素材”中的真实手绘图、56个POI、149处村景照片坐标和586张素材照片；供水节点、线路、片区及部分专题字段明确标注为示例数据。
## 启动方式

### 推荐：双击启动

在源码文件夹的上一级，也就是整个项目的外层根目录双击：

```text
启动网站.bat
```

脚本会在后台启动开发服务器，并自动打开 <http://localhost:3000>。使用结束后双击 `关闭网站.bat`。如果网站已经启动，再次双击“启动网站”只会打开浏览器，不会重复启动服务。

### 终端启动

如果终端当前位于外层根目录，先进入源码文件夹：

```powershell
cd .\平台源码
npm install
npm run dev
```

浏览器访问 <http://localhost:3000> 或 <http://127.0.0.1:3000>。本地版与GitHub在线版都优先从同一个Supabase项目读取地点、供水专题、专题记录和现场照片；连接失败时自动回退到随网站打包的本地JSON和照片。网页公开读取需要配置 `NEXT_PUBLIC_SUPABASE_URL` 与 `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`。2D云端底图还需要 `AMAP_WEB_KEY`；若使用新版高德Key，还应配置 `AMAP_SECURITY_JS_CODE`。3D首页需要可访问资产4908525的 `CESIUM_ION_TOKEN`。私密令牌和 `SUPABASE_SERVICE_KEY` 不得写入源码、网页或Git仓库。

当前用户界面只保留一个页面：

| 页面 | 地址 | 主要内容 |
| --- | --- | --- |
| 首页 | / | 默认显示高德云端2D地图，可切换无人机/手绘覆盖层或进入红塘村3D实景；2D与3D共用地点、筛选、图标、详情、供水线路和供水片区 |

## 已实现的首页功能

- 首页由 HomeExperience 管理“3D实景 / 2D地图”切换；任一时刻只挂载当前模式，减少显卡占用。
- 3D模式由 GaussianHome 与 public/cesium-viewer/index.html 加载红塘村高斯3D Tiles、世界地形、航空影像和本地无人机正射影像。
- 2D与3D共用 hongtang-real-map-features.json、hongtang-topic-records.json 和 hongtang-water-system.json。
- 当前基础地点包含56个POI和149处村景记录；2D与3D均以地图作为全屏底层，使用相同的分类筛选、矢量图钉、圆点、自动聚焦和锚定气泡详情。
- 2D地图使用高德 JavaScript API 2.0 提供道路、地名、水系等在线背景；右上角可在“高德底图、无人机影像、手绘图”之间切换，其中后两项作为半透明地理配准图层叠加在高德地图上。按住左键可向任意方向拖动，滚轮缩放，点击“回到红塘”恢复村庄中心视图。地点图标使用独立于底图缩放的DOM矢量层，并按整数屏幕像素定位；悬停和选中不再整体缩放图标，避免浏览器把SVG临时栅格化而发糊。图钉和水专题对象的点击会短暂阻止底图空白点击，防止详情气泡刚打开就被关闭。
- 地点、线路、片区和两张本地影像的原始坐标保留为WGS84；进入高德2D显示层时统一转换为GCJ-02，避免云端底图与村庄资料整体错位。原始JSON不改动，3D继续读取WGS84坐标。
- 点击地点后，两种模式都会把视图移动并缩放到对应位置，再在点位旁显示气泡；点击供水线路或片区也会聚焦到空间对象，点击地图空白处或气泡关闭按钮会取消当前选择。普通地点采用相同造型与配色的矢量图钉，密集村景记录统一为圆点，地图标签只显示“村景记录”而不显示序号。
- “专题”由HomeExperience统一持有状态并只挂载一次，不再由2D页面和3D查看器分别创建。桌面端和手机端均显示同一张白色圆角专题卡片，点击后在原位置下方展开分类多选列表；切换2D/3D只替换底层地图，专题组件本身及各图层勾选状态均不会重置；3D查看器内部的旧筛选面板已隐藏。
- “村里用水”分类右侧提供“进入”按钮，用于打开“水系统全貌、饮水从哪来、排水到哪里”三个专题视角。进入后左上角专题卡片切换为水专题导航，并暂时隐藏其他类别，帮助用户沿着水源、线路、供水点、片区、沟渠、水塘和末端去向连续阅读；退出后恢复普通专题卡片。原首页左下角的孤立入口及对应闲置样式已经删除。
- 水专题当前包含7个待核实节点、8条待核实线路（3条供水线路、5条排水线路）和3个待核实供水片区；平台已有的2处污水设施点位也会保留在“水系统全貌”和“排水到哪里”中。点击任一节点、线路或片区后，2D与3D都会突出同一组上下游和服务关系；气泡中的关联对象可继续点击，地图会自动移动到新的对象。
- 水专题详情除空间位置外，还展示节点作用、片区用水对象、共同建设与维护事项，以及需要向村民继续了解的问题。它把平台用作梳理村庄关系的工具，而不是把尚未核实的路线当成事实。
- 三维页面保留左键平移、右键围绕画面中心旋转、滚轮缩放、灵敏度设置、画质设置、回到中心和全屏功能。
- 固定页头、页脚和移动端底部导航均已移除；页面左上角悬浮显示平台Logo与名称，右侧等高显示2D/3D切换按钮。
- 已删除原地图页、记录页、村庄总览、六类事项独立路由及其专用页面组件。

## 3D高斯实景、无人机影像与原始素材

### 3D高斯实景首页

正式首页通过 `HomeExperience` 提供2D与3D双模式。进入首页时默认挂载2D地图，便于直接浏览且降低设备性能压力；切换到3D后，使用最初的在线 Cesium 资源组合：红塘村高斯模型来自 Cesium ion 资产4908525，周边地形来自 Cesium World Terrain，背景来自Bing航空影像，村庄核心区继续叠加本地无人机正射影像。切换模式时未选中的地图会被卸载。平台通过以下文件完成接入：

```text
src/app/api/cesium-ion/asset/route.ts
src/components/home/HomeExperience.tsx
src/components/home/GaussianHome.tsx
src/components/map/MapExplorer.tsx
src/components/map/AmapVillageMap.tsx
src/app/api/amap-config/route.ts
src/app/_AMapService/[...segments]/route.ts
public/cesium-viewer/index.html
public/data/hongtang-orthophoto-0.3m.webp
public/data/hongtang-orthophoto.json
public/data/hongtang-real-map-features.json
```

`/api/cesium-ion/asset` 只在服务端读取 `CESIUM_ION_TOKEN`，并向 Cesium API 请求模型资产4908525、世界地形资产1和Bing航空影像资产2的端点。浏览器只接收Cesium生成的资产访问端点和临时资产令牌，不会接触 `.env.local` 中的主令牌。部署或更换电脑时，需要在 `.env.local` 中重新配置可用令牌；`.env.example` 只保留占位符，真实令牌不得提交到Git。

本地生成的核心DSM、周边SRTM高程网格、本地晕渲和本地Cesium三维瓦片仍保存在 `public/data` 与“平台素材”中，便于后续做离线方案、数据核对或对比测试；当前正式3D首页不再读取这些本地地形和模型文件。红塘村0.3米无人机正射影像仍作为核心区覆盖层使用。

点位数据由 `prepare-real-map-data.py` 生成。POI按Excel记录生成56个地点；村景CSV按每个不同的实际坐标聚合照片，生成149处地点。最终三维场景默认加载205个地点和586张照片的索引关系。坐标只要是有效WGS84经纬度就会进入三维场景，不按红塘村手绘图范围裁切；当前有4个村景坐标位于原二维手绘图范围外，它们在二维手绘图上自然隐藏，但在三维地形中仍可通过“查看全部地点”看到。

二维和三维地点标记采用同一套视觉规则：56个POI使用清晰的SVG分类图钉，图钉中央绘制花朵、厂房、水滴、厕所、停车、学校、垃圾池、活动中心、村委会等对应矢量符号；149处密集村景记录使用小圆点；标题只在悬停或选中时显示，其中村景标签统一显示“村景记录”，不附加序号。点击地点后，两种模式都会自动移动并缩放视图。父页面从地点数据文件查找完整详情，复用 `MapDetailDrawer` 生成点位旁的气泡卡片；地图移动时持续更新气泡锚点。供水线路和片区沿用相同的点击聚焦与气泡逻辑。

查看器创建后立即使用无动画的固定视角定位红塘村中心（99.908740607°E，24.636255278°N），默认观察距离约1100米；模型和点位异步载入过程中不进入地球全览。查看器启用按需渲染，并提供“省电、均衡、清晰”三档画面质量；三档会同步调整页面分辨率倍率、在线3D Tiles屏幕误差、世界地形屏幕误差和雾效。左键水平平移、右键围绕画面中心旋转、滚轮固定比例缩放，中键停用；三个灵敏度滑块的显示范围均为0.3—2.0、步长0.1、默认1.0。成功状态不会常驻左下角；仅在加载过程或发生错误时显示必要提示。

原 SparkJS 2.1.0 轻量化成果和本地 Cesium 3D Tiles 没有删除。它们仍可用于离线预览、性能对比或未来的在线/本地混合加载，但当前正式首页使用 Cesium ion 在线模型、Cesium World Terrain和Bing航空影像。
### 真实手绘图、POI与村景照片

首页2D地图以高德在线地图为云端底层，并通过 `AMap.ImageLayer` 按地理范围叠加三农数据GeoServer的红塘村手绘图或本地无人机影像。地点、水系线路和管理片区继续叠加在同一地图中。网页运行文件为：

```text
public/data/hongtang-handdrawn-map.png
public/data/hongtang-map-layers.json
public/data/hongtang-real-map-features.json
src/components/map/AmapVillageMap.tsx
```

界面右上角提供三种显示方式：“高德底图”只显示在线道路和地名；“无人机影像”在高德底图上叠加红塘正射影像；“手绘图”叠加村庄手绘成果。两张覆盖层设置透明度，村域外仍可继续看到并拖动高德地图。若高德脚本、网络或Key不可用，页面自动回退到原有本地影像地图，不影响地点筛选和详情查看。

真实点位运行文件由`../平台素材/POI_1785232551999.xlsx`、`../平台素材/poi图片.csv`和`../平台素材/村景图片.csv`生成；当前包含56个POI、149处村景照片坐标、392张POI照片和194张村景照片，共205个地点和586张照片。586张照片已下载并压缩为WebP，正式网页从Supabase Storage的`hongtang-photos`公开素材桶读取；地点、供水专题和专题记录存放在`platform_datasets`表中。本地归档保存在`../平台素材/现场照片/web`，网页备用副本保存在`public/local-photos`，原始网址保存在`../平台素材/现场照片/photo-source-manifest.json`中。更新素材后，在`平台源码`中运行：

```powershell
python scripts/prepare-real-map-data.py
npm run prepare:map-service-assets
python scripts/localize-point-photos.py
python scripts/upload-platform-data-to-supabase.py
```

照片本地化脚本会断点续传，最长边压缩到1600像素并转换为WebP。只有全部照片都处理成功后，脚本才会更新地点JSON和本地备用副本。上传脚本把照片写入`hongtang-photos`，并同步三套共享数据；运行时只通过环境变量临时提供`SUPABASE_URL`和`SUPABASE_SERVICE_KEY`，服务器密钥不得保存到文件或提交到Git。云端更新完成后，本地版与在线版会同时看到新数据，无需把193MB照片提交到GitHub。

原始表格和GeoServer下载文件始终保存在`平台素材`，不纳入源码Git仓库。生成到`public/data`的建筑文件已脱敏；真实POI运行文件只使用表格中的点位名称、分类、简介、坐标、图片网址和资料时间，不读取或新增联系方式。

### 无人机正射影像

首页2D与3D共同使用本地无人机正射影像：3D中影像覆盖在Cesium World Terrain与Bing航空影像之上；2D中影像作为可切换的地理配准覆盖层叠加在高德地图上。两种模式读取由0.3米重采样正射影像生成的WebP展示文件和配套元数据：

```text
public/data/hongtang-orthophoto-0.3m.webp
public/data/hongtang-orthophoto.json
```

影像坐标系为 `EPSG:32647`，网页展示文件约 3.7MB。外层根目录中的 `../平台素材/Production_1-tif/` 保存约 1.92GB 的 4厘米正射影像、约 2.56GB 的 DSM，以及裁剪和重采样成果；这些原始文件不进入源码仓库。需要从 0.3 米 TIF 重新生成网页文件时，在 `平台源码` 中运行：

```powershell
npm run prepare:orthophoto
```

真实POI和村景点位会按经纬度投影到影像范围，超出当前正射影像范围的真实点位自动隐藏；问题、项目、微行动和互助资源仍使用演示或隐私安全位置。正式公开或把影像提交到GitHub前，还需要确认航拍成果、手绘图和现场照片的公开授权及敏感区域处理方式。

地图左上角筛选面板的点位分组如下：

- 村里的具体事项：小花园、茶场、茶厂、村里用水设施、光伏设施、安全隐患、村庄记忆。
- 行动与办理：村庄问题、建设项目、社区微行动、已完成行动。
- 互助资源：可提供资源、资源需求。
- 公共空间与调研资料：公共服务设施、生态资源、文化资源、调研照片、建筑、道路、水体。

真实POI、村景记录和对应照片由生成脚本统一读取，不再手工写入`src/data/mockData.ts`。后续新增或修订素材时，更新“平台素材”中的Excel/CSV后重新运行生成脚本；互动业务演示数据仍保留在`src/data/mockData.ts`。



## 项目结构

- 项目根目录：保留启动网站.bat、关闭网站.bat、使用手册和其他文档。
- 平台源码/src/app：首页、Cesium资源接口、高德客户端配置接口与安全密钥代理。
- 平台源码/src/components/home：2D/3D首页切换、持久筛选状态和三维父页面。
- 平台源码/src/components/map：高德二维地图、本地回退地图、筛选、图标与详情组件。
- 平台源码/public/cesium-viewer：正式Cesium三维查看器。
- 平台源码/public/data：地点、专题记录、供水点线面、手绘图和无人机网页影像。
- 平台素材：高斯模型、原始无人机成果、现场照片归档、地图服务原始资料和可再处理数据。

当前首页优先读取Supabase的`platform_datasets`表和`hongtang-photos`素材桶；`public/data`与`public/local-photos`仅作为连接失败时的回退。两种部署共用同一套云端数据，公开浏览器只能读取已标记为公开的数据，不能新增、修改或删除。
