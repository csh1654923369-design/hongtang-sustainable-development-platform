# 红塘村可持续发展平台 Demo

一个面向村民、共建伙伴、研究人员和管理人员的响应式网站 Demo。它围绕“发现问题—公众参与—项目推进—进展反馈—持续共建”的闭环组织页面，而不是传统村庄宣传页或联合国可持续发展目标陈列页。

> 当前所有业务数据均为演示数据，并在界面中明确标注。项目没有虚构红塘村的人口、面积、收入、历史沿革等真实统计信息。

## 启动方式

```powershell
npm install
npm run dev
```

浏览器访问 <http://localhost:3000>。本阶段不依赖 Supabase，未配置环境变量也可以完整体验 Demo。

页面右上角可以切换“游客、村民、共建伙伴、管理员”四种演示身份。部分操作会按照当前角色显示、隐藏或提示权限。

## 主要页面

| 页面 | 地址 | 主要内容 |
| --- | --- | --- |
| 首页 | `/` | 平台定位、快捷行动、议题与项目概览、地图预览 |
| 认识红塘 | `/village` | 村庄内容框架、价值与发展方向 |
| 可持续目标 | `/goals` | 本地目标卡片、指标和关联行动 |
| 共建地图 | `/map` | 地图筛选、点位详情、议题与项目联动 |
| 问题上报 | `/report` | 五步上报流程、地图定位、图片预览、提交成功反馈 |
| 共建项目 | `/projects` | 项目筛选、关注、建议、投票和活动报名 |
| 进展看板 | `/progress` | 指标卡、趋势图、项目与议题进展 |
| 参与中心 | `/participate` | 活动报名、问卷、建议与共创投票 |
| 个人中心 | `/profile` | 不同角色的议题、关注、报名与通知 |
| 研究协作 | `/research` | 研究资料提交、审核状态和成果展示 |
| 管理后台 | `/admin` | 议题受理、指派、研究审核、内容与数据管理占位 |
| 数字孪生 | `/digital-twin` | 独立的三维场景概念演示入口 |

目标、议题和项目还包含动态详情页，例如 `/goals/goal-livable`、`/issues/issue-4`、`/projects/gateway-public-space`。

## 已实现的演示闭环

- 村民完成问题上报后，可在个人中心看到新议题。
- 管理员可以受理议题、设置负责人并添加处理说明。
- 用户可以关注项目、提交建议、投票并报名参与活动。
- 用户可以填写问卷并查看演示统计结果。
- 研究人员可以提交资料，并查看待审核、通过或退回状态。
- 地图点位与议题、项目、公共空间等内容互相联动。

## 项目结构

```text
src/
  app/          Next.js 页面与路由
  components/   布局、地图、上报、项目、后台等组件
  data/         统一演示数据
  lib/          权限、标签和通用工具
  services/     议题、项目、指标、活动和内容服务接口
  types/        领域模型与状态类型
scripts/
  demo-smoke.mjs  浏览器端核心流程验收
docs/
  references/     初期产品设计参考图
supabase/
  migrations/     数据模型、RLS 与文件存储迁移
  seed.sql        本地开发演示种子
```

前端目前通过统一的 mock 数据和 service 层工作，后续接入 Supabase 时可逐步替换 service 实现，避免重写页面组件。

## 验证命令

```powershell
npm run lint
npm run typecheck
npm run build
npm run test:demo
```

`npm run test:demo` 会自动启动本地站点，并使用本机 Microsoft Edge 验证主要路由、角色交互、问题上报、项目参与、管理员处理和 390px 移动端布局。
